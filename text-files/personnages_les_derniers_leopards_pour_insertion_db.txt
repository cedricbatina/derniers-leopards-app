LES DERNIERS LÉOPARDS — FICHES PERSONNAGES POUR INSERTION DB
Version de travail générée le 2026-06-08

OBJECTIF
- Consolider les personnages retenus dans nos échanges + fichiers de travail.
- Fournir un bloc simple pour insertion dans la table characters actuelle : slug, name, description.
- Garder les éléments riches pour alimenter ensuite character_profiles, character_dossiers, character_kinships_v2 et character_aliases.

NOTES CANON / DB
- Canon : Mutinu uniquement — nkusu est obsolète (migration DB : nkusu → mutinu, nkusu en alias historique si besoin).
- Canon : Mvita Kanga (slug mvita-kanga) — pas « Vita Kanga » comme slug principal.
- Mapasa = jumeaux. Nzuzi = nom générique du premier-né ; Nsimba = nom générique du dernier-né.
- Prénoms des mapasa : Mpasi (premier-né, nzuzi) ; Muanda (dernier-né, nsimba).
- Bukono remplace Nkunku si Nkunku était le placeholder du chef faible.
- Canon orthographique : Mbuila, pas Mbwila.
- Les champs actuels de l’API characters semblent limités à slug, name, description ; les champs riches ci-dessous peuvent alimenter des tables dédiées plus tard.
